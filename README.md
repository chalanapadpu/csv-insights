# 📊 CSV Insights

An interactive web-based CSV data analysis and visualization tool.

## 🌐 Live Demo

[Open CSV Insights](https://chalanapadpu.github.io/csv-insights/)

## ✨ Features

- 📂 Upload CSV files
- 📋 Preview CSV data
- 🔍 Detect missing values
- 📊 Generate data statistics
- 📈 Visualize data with charts
- 🧹 Identify incomplete columns
- ⚡ Fast and easy browser-based analysis
- 🔒 No server-side data storage required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSV / Data Processing
- GitHub Pages
